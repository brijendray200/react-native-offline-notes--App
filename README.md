# Offline Notes

Offline Notes is a React Native Expo app for writing and editing notes with local device storage.

## Screenshot

![Offline Notes app screenshot](assets/screenshots/offline-notes-home.png)

## APK Download

[Download APK from Google Drive](https://drive.google.com/file/d/1c3XDgHvKERdsPG1P9N2tsb-wbDg6JqjH/view?usp=drive_link)

## Features

- Create, edit, and delete notes
- Saves notes locally with AsyncStorage
- Responsive layout for mobile and web
- Works offline after installation

## Run Locally

```bash
npm install
npm start
```
